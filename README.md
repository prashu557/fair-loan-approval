# LoanLens AI

LoanLens AI is a React demo for an ML-based loan approval system. It simulates an end-to-end credit workflow with applicant scoring, confidence estimates, feature explanations, and fairness checks.

## Run locally

```bash
npm install
npm start
```

## Build for production

```bash
npm run build
```

## What the app does

- Collects borrower details such as income, credit score, debt, and savings.
- Produces an ML-style approval outcome with score, confidence, and risk band.
- Shows factor contributions so the decision can be explained.
- Highlights fairness and model-governance checks alongside the prediction.
